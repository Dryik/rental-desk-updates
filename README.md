# ARAK Rental Desk

Windows desktop software for local vehicle rental shops.

[Download the latest release](https://github.com/Dryik/rental-desk-updates/releases/latest)

This repository hosts Windows installers and automatic-update files.

## Upgrading from v0.4.3

Save a backup, then download and run the v0.4.4 installer once manually. Later updates use this update feed.

## تنزيل البرنامج

[تنزيل آخر إصدار](https://github.com/Dryik/rental-desk-updates/releases/latest)

للترقية من الإصدار 0.4.3، احفظ نسخة احتياطية ثم نزّل وشغّل ملف تثبيت 0.4.4 يدوياً مرة واحدة. تستخدم التحديثات التالية مصدر التحديث هذا.
